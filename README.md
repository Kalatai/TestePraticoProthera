## Sistema de Gerenciamento de Funcionários

Projeto desenvolvido em Java com foco em Programação Orientada a Objetos (POO), utilizando herança, encapsulamento e coleções para realizar o gerenciamento de funcionários.

A aplicação realiza operações como cadastro de funcionários, remoção de registros, atualização salarial, agrupamento por função, ordenação alfabética, identificação do funcionário mais velho e cálculos relacionados à folha salarial.

O objetivo do projeto é demonstrar o uso de conceitos fundamentais da linguagem Java e da manipulação de dados utilizando estruturas da biblioteca padrão.
